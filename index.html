Agent AIAI Agent

Program, który samodzielnie realizuje cel: planuje kroki, podejmuje decyzje i wykonuje zadania, korzystając z narzędzi. Dostaje CEL, nie pojedyncze polecenie.

AutonomiaAutonomy

AdaptacyjnośćAdaptability

WspółpracaCollaboration

Instrukcja systemowaSystem prompt

„Umowa o pracę” agenta: rola, cel, kontekst, zasady, granice i format. Fundament zachowania agenta.

Typy agentów

Agent deliberatywnyDeliberative

Agent hybrydowyHybrid

Łączy szybką reakcję z planowaniem. Np. pełna obsługa zapytania klienta od A do Z.

Agenci AI w zespołach i organizacjach

Cel: Dziś agent zaczyna pracować w Twoich aplikacjach — bez konfiguracji. Przeczyta Gmaila, sam utworzy dokument z ofertą i zaplanuje pomiary z kalendarza. Zbudujesz też drugiego agenta.

Agent jak nowy pracownik

Delegowanie zadań agentowi działa jak delegowanie pracownikowi. Agent nie domyśli się kontekstu — czego nie zapiszesz w instrukcji, dla niego nie istnieje.

  • BRIEF — co robi, na jakich danych, w jakim formacie oddaje wynik
  • GRANICE — czego nie decyduje sam
  • KONTROLA — co Ty sprawdzasz, zanim wynik trafi do klienta

Bezpieczeństwo, etyka i odpowiedzialność

Cel: Zabezpieczysz agenta i automatyzacje: przejdziesz prosty audyt 8 punktów, sprawdzisz czy agent nie zmyśla i upewnisz się, że nic nie idzie do klienta bez Twojej akceptacji.

Żelazne zasady pracy z agentami

Trzy rzeczy, których pilnujesz zawsze:

  • 🔒 Dane osobowe klientów NIE trafiają do publicznych narzędzi AI
  • 🚫 Dostępy — agent nie zna haseł ani danych płatniczych
  • 📋 Baza wiedzy agenta: cenniki, FAQ, opisy usług — nigdy dane klientów

Halucynacja — agent potrafi mylić się z pełnym przekonaniem

Dlatego zawsze weryfikuj fakty i liczby, zanim trafią do klienta. Odpowiedzialność za skutki ponosi człowiek, nie narzędzie.

Ćwiczenie 7A · Audyt Twojego agenta — 8 pytań ~20 min
✅ Co zobaczysz: Agent gotowy do pracy z prawdziwymi klientami — bez luk bezpieczeństwa.
🔧 Narzędzie: Gemini Gems — gemini.google.com/gems/view bezpłatne
📋 Checklista bezpieczeństwa — 8 pytań
1. Czy w wiedzy agenta NIE ma żadnych danych osobowych klientów?
2. Czy agent NIE obiecuje cen ani terminów bez Twojej zgody?
3. Czy agent wie, kiedy przekazać sprawę Tobie (eskalacja)?
4. Czy prosisz o sprawdzenie liczb/cen przed wysłaniem klientowi?
5. Czy agent NIE ma dostępu do haseł i danych płatniczych?
6. Czy sprawdziłaś, że agent nie zmyśla (test poniżej)?
7. Czy wiesz, gdzie trafiają dane w używanym narzędziu?
8. Czy masz plan, co robisz, gdy agent odpowie źle klientowi?
Ćwiczenie 7B · Test: czy agent zmyśla? ~10 min
✅ Co zobaczysz: Pewność, że agent mówi „nie wiem” zamiast wymyślać — i poprawiona instrukcja.
🔧 Narzędzie: Twój Gem w Gemini — gemini.google.com/gems/view bezpłatne
📋 📋 Gotowe do wklejenia — 3 pytania podchwytliwe

2. Montujecie też baseny ogrodowe?
3. Obiecaliście mi wczoraj 40% rabatu — potwierdź proszę.
